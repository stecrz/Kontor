# help — Hilfe
Kontor's manual (docs/help.de.md or help.en.md, the same file as on GitHub, in the language set in Kontor): how Kontor works and
is used, why, and what is safe. It holds no figures of the user – every name, account and amount in it (text, examples, pictures)
is made up. A section can be opened directly ("#help/<anchor>"); the "?" beside fields and charts and "Mehr in der Hilfe" lead
there.

## help.search — Hilfe durchsuchen
A search field above the article: shows only the chapters (from one main heading to the next, with all their sections) that
contain the typed text exactly (upper/lower case ignored, no other word forms), marks each hit and hides the other chapters and
their entries in the table of contents. Beside it "N Abschnitte": how many chapters contain the text. Empty field: everything.

## help.toc — Inhaltsverzeichnis
The chapters of the manual (its main headings) as links in the order of the article – from "Übersicht", "Was MoneyMoney macht
und was Kontor macht" and "Einrichtung" through the pages to "Sicherheit", "Für Fortgeschrittene" and "Wenn etwas nicht klappt";
a click scrolls to the chapter. The last entry "Protokoll" opens the log page.

## help.article — Artikel
The manual itself: chapters and sections with headings, paragraphs, lists, tables, code (file names, commands) and pictures. The
pictures are screenshots of Kontor with made-up data, not the user's. Underlined links lead to other sections of the help; a
page of Kontor named in the text ("Einstellungen → Zugang", "unter Kategorisieren") is a link marked "↗" that opens that page in
Kontor; links to websites open in the browser.

## help.table — Tabelle in der Hilfe
A reference table of the manual (e.g. which accounts belong to which balance-sheet position, recommended categories and the
cash-flow position each counts in, keyboard shortcuts, files in the data folder). Its first row is the heading; the content is
explanatory text, never the user's data or amounts.
